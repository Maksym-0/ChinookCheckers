To run the engine, you need to download the endgame databases (WLD db).
Due to file size limits, they are not included in this repository.

1. Download the "Kingsrow English 2 through 8 pieces WLD db" from here:
	https://edgilbert.org/EnglishCheckers/KingsRowEnglish.htm
2. Extract the .bin files into this directory (ChinookCheckers.Infrastructure/Engine/db/).
